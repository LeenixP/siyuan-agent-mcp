# v3.1.2

## Fixes

- Fixed a v3.1.1 regression where `siyuan_update_block` silently kept only the first block when given multi-block Markdown.
- Applied the same safe expansion behavior to `siyuan_batch_update_blocks`.
- Regular-block multi-block updates now update the target block with the first Markdown block, then insert the remaining Markdown blocks immediately after the target block.
- Document-block updates are still passed to SiYuan as full-document replacements.

## Structured Output

- `siyuan_update_block` and `siyuan_batch_update_blocks` now return:
  - `expanded`: whether the Markdown replacement was split into multiple block operations.
  - `insertedBlockIds`: block IDs inserted for the trailing Markdown blocks.

## Documentation And Tests

- Added regression tests for heading-plus-body updates, multi-paragraph updates, list handling, fenced-code handling, and single-block soft-wrapped paragraphs.
- Updated README tool descriptions for multi-block update behavior.
