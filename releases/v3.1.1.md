# v3.1.1

## Fixes

- Fixed `siyuan_create_doc` handling for Markdown strings that contain literal escaped line breaks such as `\n`; these are normalized before being sent to SiYuan so headings, paragraphs, and lists are parsed into separate blocks.
- Fixed `siyuan_create_doc` duplicate behavior for existing human-readable paths. Existing documents are returned with `existed=true` and `created=false` instead of creating same-name duplicates.
- Adjusted `siyuan_batch_insert_blocks` for same-parent parentID-only batches so final document order matches input order.

## Documentation And Tests

- Documented `siyuan_create_doc` duplicate-path behavior and Markdown newline normalization.
- Documented same-parent batch insert ordering behavior.
- Added regression tests for Markdown normalization, duplicate-path create behavior, and batch insert ordering.
