# v3.1.0

## Highlights

- Added daily-note workflows: create/open daily notes and append or prepend blocks.
- Added batch editing tools for inserting and updating blocks.
- Added path resolution tools for document IDs, storage paths, and human-readable paths.
- Added asset inspection tools for document assets, missing assets, unused assets, and asset path resolution.
- Added notebook metadata, notebook icon, and gated notebook deletion tools.
- Added batch attribute updates for block metadata.

## Fixes

- Corrected asset-content search ordering to match SiYuan's asset search API.
- Updated document reads so Markdown content is present in the text result as well as structured output.
- Unified truncation metadata for document and block reads.
- Returned transaction operation IDs from write tools instead of placeholder IDs.
- Improved document creation by passing parent document IDs and reporting whether a path already existed.

## Safety And Operations

- Added `SIYUAN_ENABLE_DANGEROUS_TOOLS` to keep high-risk tools hidden by default.
- Added `SIYUAN_MAX_CONCURRENCY` to limit kernel request fan-out.
- Added `SIYUAN_RETRY_INDEXING_MS` for one retry when SiYuan reports indexing in progress.
- Strengthened destructive confirmation for notebook deletion with both `confirmId` and exact `confirmText`.

## Documentation And Tests

- Added Chinese default documentation in `README.md` and English documentation in `README_EN.md`.
- Updated README and `.env.example` for new tools and environment variables.
- Added tool contract tests for SiYuan request mappings.
- Expanded helper, client, and tool-registration tests.
