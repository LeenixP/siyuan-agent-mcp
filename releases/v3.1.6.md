# v3.1.6

## Fixes

- Prevented accidental YAML front matter and tag-only lines from being written as visible document body content during `siyuan_create_doc`.
- Normalized `siyuan_create_doc.tags` from comma-separated text, string arrays, or `#tag#` tokens into SiYuan's comma-delimited document tag format.
- Added `tags` support to `siyuan_set_block_attrs` and `siyuan_batch_set_block_attrs`, including the same tag normalization behavior.

## Improvements

- Added structured `warnings` to body block write tools when Markdown appears to contain document metadata.
- Clarified tool descriptions and documentation so document metadata tags are routed through `tags` parameters or block attributes instead of visible Markdown body text.

## Tests

- Added formatter coverage for tag normalization, YAML front matter extraction, loose metadata extraction after headings, and metadata warnings.
- Added contract coverage for `siyuan_create_doc` metadata cleanup, explicit tag normalization, block metadata warnings, and `siyuan_set_block_attrs` tag writes.
