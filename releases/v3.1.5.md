# v3.1.5

## Features

- Added `siyuan_upload_assets` for multipart asset upload from local paths, base64 payloads, or text content, with optional upload-then-insert.
- Added `siyuan_import_local_assets` for kernel-side local asset import/linking, intended for large media files and paths already visible to SiYuan.
- Added `siyuan_insert_asset_blocks` for inserting existing `assets/...`, `file://`, and http(s) resources as image/audio/video/file blocks.
- Added `siyuan_insert_slash_block`, a high-level tool for common SiYuan `/` menu content including image, audio, video, iframe, widget, HTML, code, math, callout, table, Mermaid, PlantUML, Graphviz, FlowChart, ECharts, Mind map, and ABC blocks.

## Improvements

- Added multipart/form-data support to `SiYuanClient`.
- Added `WRITE_EXTERNAL` tool annotations for tools that write while interacting with local files or external URLs.
- Updated the server-reported MCP version to match the package version.

## Tests

- Added contract coverage for asset upload insertion, kernel-local asset import, inferred audio/video snippets, iframe insertion, and diagram block generation.
