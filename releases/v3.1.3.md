# v3.1.3

## Fixes

- Fixed `siyuan_update_block` and `siyuan_batch_update_blocks` `insertedBlockIds` reporting for regular-block multi-block Markdown updates.
- Expanded trailing Markdown blocks are now inserted one block at a time, so each inserted block ID is returned when SiYuan reports it.
- Preserved insertion order by anchoring each trailing block after the previously inserted block.

## Documentation And Tests

- Added regression coverage for three-block Markdown updates, verifying that all trailing inserted block IDs are returned.
- Updated README release links.

## Validation

- `npm test`
- `npm pack --dry-run`
